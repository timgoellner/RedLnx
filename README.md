# RedLnx
RedLnx is a Python Programm that imitates the Linux shell

## Implemented Commands:
- clear
- ls [-la] [directory]
- cd [directory]
- echo [-n] [string ...]
- help [pattern]
- exit
- mkdir [-p] [directories ...]
- rmdir [-rf] [directories ...]
- touch [files ...]
- rm [files ...]
- useradd [-m] [user]
- userdel [-r] [user]
- passwd [user]
- pwd
- su [-p] [user]
- vi [file]
- cat [file]
